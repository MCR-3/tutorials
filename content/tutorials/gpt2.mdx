The previous article assembled the transformer block: multi-head attention and a feed-forward network, each wrapped in a Pre-LN residual connection. Stacking $N$ identical blocks produces a powerful sequence processor. What it is not yet is a language model. Two things are still missing: a way to convert a token ID sequence into the $T \times D$ tensors the blocks expect, and a way to convert the blocks' $T \times D$ output back into a probability distribution over the vocabulary. GPT-2 adds both, and the result is a complete, trainable language model.

## The Language Modeling Objective

A language model assigns a probability to a sequence of tokens. The autoregressive factorization decomposes this into a product of conditional probabilities:

$$
P(t_1, t_2, \ldots, t_T) = \prod_{i=1}^{T} P(t_i \mid t_1, \ldots, t_{i-1})
$$

At each position $i$, the model receives the preceding context and produces a probability distribution over the $V$-token vocabulary. Training maximizes the log-likelihood of the training data, which is equivalent to minimizing the average cross-entropy:

$$
\mathcal{L} = -\frac{1}{T} \sum_{i=1}^{T} \log P(t_i \mid t_1, \ldots, t_{i-1})
$$

This is the same cross-entropy loss introduced in the Loss Functions article, applied at every position in the sequence. Because the transformer processes all positions in parallel, a single forward pass of length $T$ produces $T$ independent next-token predictions simultaneously. Causal masking in each attention layer ensures position $i$ cannot see tokens $t_{i+1}, \ldots, t_T$ during this computation.

## Architecture Overview

<GPT2Diagram />

The model has three stages.

**Input stage.** A sequence of token IDs is converted to $D$-dimensional vectors by combining two learned embedding tables.

**Body.** The sequence flows through $N$ identical transformer blocks in series. The shape $T \times D$ is preserved at every block boundary.

**Output stage.** A final layer normalization is applied to the output of the last block, then a linear projection maps each position from $\mathbb{R}^D$ to $\mathbb{R}^V$ logits. Softmax produces the next-token probability distribution.

## Input Embeddings

Two learned tables combine to form the input to the first block:

$$
\mathbf{x}_t = \mathbf{E}[t_t] + \mathbf{P}[t]
$$

$\mathbf{E} \in \mathbb{R}^{V \times D}$ is the token embedding table from the Tokenization and Embeddings article: each row is a $D$-dimensional learned vector for one vocabulary entry.

$\mathbf{P} \in \mathbb{R}^{T_{\max} \times D}$ is a learned positional embedding table. The Positional Encoding article presented sinusoidal encodings computed from a fixed formula. GPT-2 takes a simpler approach: it allocates one trainable row for each of the $T_{\max} = 1{,}024$ positions it supports, and lets gradient descent find the best representation for each position. The two tables are added element-wise before the first block, so every position enters with both its token identity and its location encoded.

For GPT-2 small ($D = 768$, $V = 50{,}257$):

| Table | Shape | Parameters |
|-------|-------|-----------|
| Token embedding $\mathbf{E}$ | $50{,}257 \times 768$ | $\approx 38.6\text{ M}$ |
| Positional embedding $\mathbf{P}$ | $1{,}024 \times 768$ | $\approx 0.8\text{ M}$ |

## Weight Tying

The output stage needs a matrix of shape $D \times V$ to project hidden states to logits. This is exactly the transpose of the token embedding table $\mathbf{E} \in \mathbb{R}^{V \times D}$.

GPT-2 reuses the same matrix for both purposes:

$$
\text{logit}_v = \mathbf{h} \cdot \mathbf{E}[v]
$$

where $\mathbf{h} \in \mathbb{R}^D$ is the normalized hidden state at some position. The model predicts the next token by measuring how similar the current hidden state is to each row of the embedding table. This weight tying removes $V \times D \approx 38.6\text{ M}$ parameters from the count and tends to improve performance: the embedding space used to represent input tokens is forced to be consistent with the space used to score output tokens.

## The LM Head

The complete output computation for a position is:

$$
\mathbf{logits} = \text{LN}(\mathbf{h}) \cdot \mathbf{E}^\top \in \mathbb{R}^V
$$

where $\mathbf{h} \in \mathbb{R}^D$ is the output of the last transformer block. GPT-2 introduced a final layer normalization after the last block, applied before the output projection. Applying softmax to the logits produces the probability distribution over the next token.

During training, logits at position $i$ are compared against the ground-truth token $t_{i+1}$ with cross-entropy. The sequence is shifted by one: the input to the model is $[t_1, \ldots, t_{T-1}]$ and the targets are $[t_2, \ldots, t_T]$, so every position has a label.

## Autoregressive Generation

Training uses teacher forcing: the correct tokens are fed at every step regardless of what the model predicts. At inference time, the model instead conditions each new token on its own previous outputs.

Given a prompt $[t_1, \ldots, t_T]$:

1. Run a forward pass. The logits at position $T$ encode the distribution for $t_{T+1}$.
2. Sample $t_{T+1}$ from this distribution.
3. Append $t_{T+1}$ to the sequence.
4. Repeat from step 1 with the extended context.

Generation terminates when the model produces a special end-of-sequence token or a maximum length is reached.

**Temperature.** Before sampling, the logits are divided by a temperature $\tau > 0$:

$$
P(t) = \text{softmax}\!\left(\frac{\mathbf{logits}}{\tau}\right)
$$

$\tau = 1$ leaves the model's learned distribution unchanged. $\tau < 1$ concentrates probability on the highest-scoring tokens, producing more predictable output. $\tau > 1$ spreads probability more evenly, producing more varied output.

**Top-$k$ sampling.** Before softmax, all logits below the $k$-th highest are set to $-\infty$. Only the $k$ most likely candidates survive. GPT-2's original paper used $k = 40$.

**Top-$p$ (nucleus) sampling.** Instead of a fixed $k$, retain the smallest set of tokens whose cumulative probability exceeds $p$, and sample from that set. At $p = 0.9$ the model draws from the top 90% of probability mass, with the number of candidates adapting automatically to the model's confidence at each step.

## Complete Parameter Count

For GPT-2 small ($D = 768$, $H = 12$, $N = 12$, $V = 50{,}257$, $T_{\max} = 1{,}024$):

| Component | Parameters |
|-----------|-----------|
| Token embedding $\mathbf{E}$ | $50{,}257 \times 768 \approx 38.6\text{ M}$ |
| Positional embedding $\mathbf{P}$ | $1{,}024 \times 768 \approx 0.8\text{ M}$ |
| 12 transformer blocks ($\approx 12D^2$ each) | $12 \times 7.1\text{ M} \approx 85.1\text{ M}$ |
| Final LayerNorm ($2D$) | $1{,}536$ |
| LM head (tied to $\mathbf{E}$) | $0$ (shared) |
| **Total** | $\approx 124\text{ M}$ |

The token embedding table accounts for 31% of the total at this scale. As models grow wider and deeper, the transformer blocks dominate: each block holds $12D^2$ parameters, which grows quadratically with $D$ while the embedding tables grow only linearly.

## In Code

```simplegrad
import simplegrad as sg
import numpy as np

# ═══════════════════════════════════════════════════════════════════════════════
# Building blocks from previous articles — all sg.nn.Module subclasses
# ═══════════════════════════════════════════════════════════════════════════════

class MultiHeadAttention(sg.nn.Module):
    def __init__(self, D, H):
        assert D % H == 0
        super().__init__()
        self.H, self.dk = H, D // H
        self.WQ = [sg.nn.Linear(D, self.dk, use_bias=False) for _ in range(H)]
        self.WK = [sg.nn.Linear(D, self.dk, use_bias=False) for _ in range(H)]
        self.WV = [sg.nn.Linear(D, self.dk, use_bias=False) for _ in range(H)]
        self.WO = [sg.nn.Linear(self.dk, D, use_bias=False) for _ in range(H)]

    def forward(self, x, causal=True):
        T, dk, out = x.shape[0], self.dk, None
        for h in range(self.H):
            Q, K, V = self.WQ[h](x), self.WK[h](x), self.WV[h](x)
            scores  = Q @ K.T / dk ** 0.5
            if causal:
                mask = np.triu(np.ones((T, T), dtype="float32"), k=1) * -1e9
                scores = scores + sg.Tensor(mask, comp_grad=False)
            contrib = self.WO[h](sg.softmax(scores, dim=-1) @ V)
            out = contrib if out is None else out + contrib
        return out

class LayerNorm(sg.nn.Module):
    def __init__(self, D, eps=1e-5):
        super().__init__()
        self.gamma = sg.ones((D,),  comp_grad=True)
        self.beta  = sg.zeros((D,), comp_grad=True)
        self.eps   = eps

    def forward(self, x):
        mu  = sg.mean(x, dim=-1)
        var = sg.mean((x - mu) ** 2, dim=-1)
        return (x - mu) / (var + self.eps) ** 0.5 * self.gamma + self.beta

class FFN(sg.nn.Module):
    def __init__(self, D):
        super().__init__()
        self.fc1 = sg.nn.Linear(D, 4 * D)
        self.fc2 = sg.nn.Linear(4 * D, D)

    def forward(self, x):
        return self.fc2(sg.gelu(self.fc1(x)))

class TransformerBlock(sg.nn.Module):
    def __init__(self, D, H):
        super().__init__()
        self.ln1 = LayerNorm(D)
        self.mha = MultiHeadAttention(D, H)
        self.ln2 = LayerNorm(D)
        self.ffn = FFN(D)

    def forward(self, x, causal=True):
        x = x + self.mha(self.ln1(x), causal=causal)
        x = x + self.ffn(self.ln2(x))
        return x

# ═══════════════════════════════════════════════════════════════════════════════
# GPT-2: assembles every piece into a complete language model
# ═══════════════════════════════════════════════════════════════════════════════

class GPT2(sg.nn.Module):
    """Decoder-only transformer language model (GPT-2 architecture).

    Token embeddings and the LM head share the same weight matrix (weight
    tying). Gradients flow to wte.weight from both the embedding lookup and
    the output projection — simplegrad accumulates them automatically.
    """

    def __init__(self, V: int, D: int, H: int, N: int, T_max: int = 1024):
        super().__init__()
        self.wte    = sg.nn.Embedding(V, D)                    # token embeddings
        self.wpe    = sg.nn.Embedding(T_max, D)                # positional embeddings
        self.blocks = [TransformerBlock(D, H) for _ in range(N)]
        self.ln_f   = LayerNorm(D)                             # final layer norm

    def forward(self, idx):
        # idx: list of integer token IDs, length T
        T     = len(idx)
        idx_t = sg.Tensor(np.array(idx), dtype="int32")        # must be int for indexing
        pos_t = sg.Tensor(np.arange(T),  dtype="int32")
        x     = self.wte(idx_t) + self.wpe(pos_t)             # (T, D)
        for block in self.blocks:
            x = block(x, causal=True)
        x = self.ln_f(x)
        return x @ self.wte.weight.T                           # (T, V) — weight-tied LM head

    def loss(self, idx):
        """Next-token prediction loss over the full sequence."""
        logits    = self(idx[:-1])                             # (T-1, V): predict tokens 1..T
        T_1, V    = logits.shape
        targets   = sg.zeros((T_1, V), comp_grad=False)
        for i, t in enumerate(idx[1:]):
            targets.values[i, t] = 1.0                        # one-hot: next token at each step
        return sg.ce_loss(logits, targets)                     # scalar cross-entropy

# ── Autoregressive generation ─────────────────────────────────────────────────

def generate(model: GPT2, prompt: list, max_new_tokens: int = 10,
             temperature: float = 1.0) -> list:
    """Sample tokens one by one, feeding each output back as input."""
    model.set_eval_mode()
    idx = list(prompt)
    with sg.no_grad():
        for _ in range(max_new_tokens):
            ctx        = idx[-1024:]                           # truncate to context window
            logits_np  = model(ctx).values[-1]                 # (V,) — last position only
            logits_np  = (logits_np - logits_np.max()) / temperature  # stability + temperature
            probs      = np.exp(logits_np) / np.exp(logits_np).sum()
            next_tok   = int(np.random.choice(len(probs), p=probs))
            idx.append(next_tok)
    return idx

# ═══════════════════════════════════════════════════════════════════════════════
# Training demo — tiny model (fast to run), same loop as any real GPT-2
# ═══════════════════════════════════════════════════════════════════════════════

V, D, H, N = 64, 16, 2, 2        # tiny: vocab=64, d_model=16, 2 heads, 2 layers
model     = GPT2(V=V, D=D, H=H, N=N, T_max=32)
optimizer = sg.opt.Adam(model, lr=1e-2)

model.summary()
# wte.Embedding_weight       (64, 16)   1 024   ← also used as LM head (weight tying)
# wpe.Embedding_weight       (32, 16)     512
# blocks.0.ln1.gamma / beta   (16,)  ×2   32
# blocks.0.mha.WQ/K/V/O[h]  (16,8) ×8   ...
# blocks.0.ffn.fc1/fc2        ...
# ...

model.set_train_mode()
for step in range(30):
    seq  = list(np.random.randint(0, V, 10))   # random 10-token sequence
    optimizer.zero_grad()
    loss = model.loss(seq)                      # next-token CE over all 9 positions
    loss.backward()                             # BPTT through N blocks + embedding
    optimizer.step()

    if step % 10 == 0:
        print(f"step {step:2d}  loss={float(loss.values):.4f}")

# ── Generation ────────────────────────────────────────────────────────────────
prompt    = [1, 5, 12]
generated = generate(model, prompt, max_new_tokens=7, temperature=0.8)
print("prompt   :", prompt)
print("generated:", generated)   # [1, 5, 12, <7 sampled tokens>]
```

```pytorch
import torch
import torch.nn as nn
import torch.nn.functional as F

class GPT2(nn.Module):
    def __init__(self, vocab_size: int, d_model: int, num_heads: int,
                 n_layers: int, max_len: int = 1024):
        super().__init__()
        self.wte     = nn.Embedding(vocab_size, d_model)
        self.wpe     = nn.Embedding(max_len, d_model)
        self.blocks  = nn.ModuleList([
            TransformerBlock(d_model, num_heads) for _ in range(n_layers)
        ])
        self.ln_f    = nn.LayerNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)
        self.lm_head.weight = self.wte.weight      # weight tying

    def forward(self, idx: torch.Tensor) -> torch.Tensor:
        B, T = idx.shape
        pos  = torch.arange(T, device=idx.device).unsqueeze(0)   # (1, T)
        x    = self.wte(idx) + self.wpe(pos)                      # (B, T, D)
        for block in self.blocks:
            x = block(x, causal=True)
        return self.lm_head(self.ln_f(x))                         # (B, T, V)

    def loss(self, idx: torch.Tensor) -> torch.Tensor:
        logits  = self(idx[:, :-1])               # (B, T-1, V)
        targets = idx[:, 1:].contiguous()          # (B, T-1)
        B, T, V = logits.shape
        return F.cross_entropy(logits.view(B * T, V), targets.view(B * T))

@torch.no_grad()
def generate(model: GPT2, idx: torch.Tensor, max_new_tokens: int,
             temperature: float = 1.0, top_k: int = 0) -> torch.Tensor:
    model.eval()
    for _ in range(max_new_tokens):
        ctx    = idx if idx.size(1) <= 1024 else idx[:, -1024:]
        logits = model(ctx)[:, -1, :] / temperature          # (B, V)
        if top_k > 0:
            v, _ = torch.topk(logits, min(top_k, logits.size(-1)))
            logits[logits < v[:, [-1]]] = float('-inf')
        probs    = F.softmax(logits, dim=-1)
        next_tok = torch.multinomial(probs, num_samples=1)   # (B, 1)
        idx      = torch.cat([idx, next_tok], dim=1)
    return idx

# GPT-2 small: ~124 M parameters
model = GPT2(vocab_size=50257, d_model=768, num_heads=12, n_layers=12)
x     = torch.randint(0, 50257, (2, 64))    # batch=2, seq_len=64
print(model(x).shape)                        # torch.Size([2, 64, 50257])

total = sum(p.numel() for p in model.parameters())
print(f"{total:,}")                           # ≈ 124,475,904
```

---

GPT-2 brings together every concept covered in this series: the tokenizer and BPE vocabulary, learned embeddings with weight tying, positional encodings for sequence order, causal self-attention that gives each position direct access to all preceding positions, multi-head attention for parallel specialization, residual connections and layer normalization for training stability, and the position-wise feed-forward network for per-position transformation. Stacking $N$ of these blocks and training on next-token prediction over a large text corpus is, in its essentials, how modern language models are built.
